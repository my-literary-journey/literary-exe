MY LITERARY JOURNEY
A Great Books Digital Portfolio

Welcome to My Literary Journey, a digital portfolio created as part of my Great Books course.

This website presents my literary explorations, reflections, and learning experiences through an interactive digital library inspired by vintage books and classic literature.

About the Project

The website was designed to provide a unique reading experience where visitors can explore literary works through interactive book covers and discover the ideas, lessons, and reflections found within each collection.

Features

- Vintage-inspired library design
- Interactive digital book collection
- Student profile
- Literary reflections and learning journal
- Background music with playback controls
- Animated book-opening experience
